# TAKEOVER Lyric Stage — 文字PV (リリックアプリ)

初音ミク「マジカルミライ 2026」プログラミング・コンテスト応募作品。
TextAlive App API と Three.js を用いた、ライブ会場風の 3D 文字PV アプリケーションです。

- 対象楽曲: **TAKEOVER / Twinfield** (<https://piapro.jp/t/E2i3>)
- 歌詞のフレーズ・単語・文字の発声タイミングと声量に同期して、3D 歌詞演出・背景・ダンサーが連動します

## 起動方法

ビルドは不要です。本リポジトリのファイル一式を HTTP サーバ上に設置するだけで動作します
(動的なサーバ処理は一切使用していません)。

ローカルで確認する場合は、リポジトリ直下で任意の静的 HTTP サーバを起動してください。

```bash
# 例 1: Python
python3 -m http.server 8000

# 例 2: Node.js (npx)
npx serve .
```

ブラウザで <http://localhost:8000> (例 2 の場合は表示された URL) を開き、
▶ ボタンを押すと楽曲の読み込みと再生が始まります。

> **注意**: `file://` で直接 index.html を開くと CORS の制約で歌詞データを取得できません。
> 必ず HTTP サーバ経由で開いてください (アプリ内にも案内が表示されます)。

## 動作確認環境

パソコン用の Web ブラウザ (Google Chrome 最新版) を意図した環境としています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | エントリーポイント。CDN 依存の読み込みと画面レイアウト |
| `style.css` | ライブ会場風 UI のスタイル |
| `app.js` | TextAlive App API の制御。再生・歌詞イベント・拍/サビ/声量情報を `window.MusicBG` へ配信 |
| `bg.js` | 背景シーン (光の筋・星・波紋・ブルーム/残像ポストエフェクト) |
| `lyrics3d.js` | 3D 歌詞演出エンジン (曲のセクションに応じた出現パターン切り替え) |
| `dancer.js` | ダンサー。歌詞の単語・フレーズ進行・声量に同期して踊る |

## 使用ライブラリ (すべて CDN 読み込み・バージョン固定)

- [TextAlive App API](https://developer.textalive.jp/) 0.4.0
- [Three.js](https://threejs.org/) 0.165.0 (importmap による ES Modules)
- axios 1.17.0 (TextAlive App API の依存ライブラリ)

ビルドツールは使用していないため、ビルド用スクリプトはありません。
ソースコードに難読化などの機械処理は行っていません。

## 操作方法

- **▶ / Ⅱ / ■ / ↺ / |<**: 再生・一時停止・停止・先頭へ・歌詞の先頭へ
- **シークバー**: 任意の位置へ移動
- **音量スライダー**: 音量調整
- TextAlive ホスト接続時はホスト側の操作に追従します (文字サイズ・アクセント色のパラメータ対応)
