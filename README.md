# TAKEOVER Lyric Stage — 文字PV (リリックアプリ)

初音ミク「マジカルミライ 2026」プログラミング・コンテスト応募作品。
TextAlive App API と Three.js を用いた、ライブ会場風の 3D 文字PV アプリケーションです。

- 対象楽曲: **TAKEOVER / Twinfield** (<https://piapro.jp/t/E2i3>)
- 歌詞のフレーズ・単語・文字の発声タイミングと声量に同期して、3D 歌詞演出・背景・ダンサーが連動します

## 起動方法

ビルドは不要です。本リポジトリのファイル一式を HTTP サーバ上に設置するだけで動作します
(動的なサーバ処理は一切使用していません)。

ローカルで確認する場合は、リポジトリ直下で任意の静的 HTTP サーバを起動してください。

```bash
# 例 1: PHP
php -S localhost:8080

# 例 2: Node.js (npx)
npx serve .
```

ブラウザで <http://localhost:8000> (例 2 の場合は表示された URL) を開き、
▶ ボタンを押すと楽曲の読み込みと再生が始まります。

> **注意**: `file://` で直接 index.html を開くと CORS の制約で歌詞データを取得できません。
> 必ず HTTP サーバ経由で開いてください (アプリ内にも案内が表示されます)。

## 動作確認環境

パソコン用の Web ブラウザ (Google Chrome 最新版) を意図した環境としています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | エントリーポイント。CDN 依存の読み込みと画面レイアウト |
| `style.css` | ライブ会場風 UI のスタイル |
| `app.js` | TextAlive App API の制御。再生・歌詞イベント・拍/サビ/声量情報を `window.MusicBG` へ配信 |
| `bg.js` | 背景シーン (光の筋・星・波紋・ブルーム/残像ポストエフェクト) |
| `lyrics3d.js` | 3D 歌詞演出エンジン (曲のセクションに応じた出現パターン切り替え) |
| `dancer.js` | ダンサー。歌詞の単語・フレーズ進行・声量に同期して踊る |

## 使用ライブラリ (すべて CDN 読み込み・バージョン固定)

- [TextAlive App API](https://developer.textalive.jp/) 0.4.0
- [Three.js](https://threejs.org/) 0.165.0 (importmap による ES Modules)
- axios 1.17.0 (TextAlive App API の依存ライブラリ)

ビルドツールは使用していないため、ビルド用スクリプトはありません。
ソースコードに難読化などの機械処理は行っていません。

## 歌詞演出の仕組み

歌詞は **フレーズ・単語・文字** の3粒度で個別に演出が動きます。
担当ファイルは `textpv.js`（ロジック）と `style.css`（アニメーション定義）です。

---

### フレーズ（`onPhrase`）— メインの歌詞表示

フレーズが来るたびに **variant（登場スタイル）** と **tone（色）** が決まり、画面に表示されます。  
どちらも「フレーズ本文のハッシュ値 × セクション」で決定されるため、同じフレーズは常に同じ見た目になります。

#### variant（登場スタイル）

| variant | 配置 | 動き |
|---|---|---|
| **slide** | 左下 | 左からスライドイン |
| **slash** | 右中央・斜め傾き | マスクが左→右にスイープ |
| **echo** | 左上 | マスクスイープ＋半透明コピー残像×3 |
| **glitch** | 中央下 | 横ずれグリッチ×2コマ＋コピー残像×2 |
| **burst** | 中央 | マスクスイープ・中央ドン |
| **vertical** | 右上・縦書き | 上からドロップ |

#### variant × セクション対応

| セクション | 使用 variant | 使用 tone |
|---|---|---|
| intro | slide / slash / echo / glitch | cyan / white |
| amelo | slide / slash / echo / glitch | cyan / white |
| bmelo | vertical / slash / echo | cyan / white |
| chorus | burst / glitch / slide | hot / warm / white |
| interlude | echo / slash / vertical | cyan / warm |
| finale | burst / slide / glitch | warm / white / hot |

#### tone（色）

| tone | 色 |
|---|---|
| **cyan** | ターコイズ（`#39c5bb` 系） |
| **hot** | ピンク（`#ff5ca8` 系） |
| **warm** | 黄色（`#ffd166` 系） |
| **white** | 白 |

#### フレーズ内の構造

- **文字を1つずつ `<span>` 化**し、`--i` インデックス × 31ms のディレイで1文字ずつポップイン
- **キーワード強調**：フレーズ内で最も文字数の多い単語（2文字以上の意味のある語）を "核" とし、その文字だけ `scale: 1.2` + RGBずらしグロー、それ以外は `opacity: 0.6 / scale: 0.9` に抑える
- **サビ（is-chorus）のキーワード**：声量（CSS変数 `--pv-vocal`）に合わせてリアルタイムで脈動（`scale: 1.18 + vocal × 0.24`）
- **カットライン**：フレーズ登場と同時に斜めラインが3本フラッシュ
- **マスクスイープ**：`clip-path` が左→右に 0.62秒で開いてワイプ登場

#### フォントサイズ（文字数による自動切り替え）

| クラス | 文字数 | フォントサイズ（PC） |
|---|---|---|
| pv-short | 〜9文字 | 5.1rem |
| pv-medium | 10〜20文字 | 4rem |
| pv-long | 21文字〜 | 2.85rem |

#### 同時表示数

最大 **3フレーズ**。超えると古いものからフェードアウト退場。

---

### 単語（`onWord`）— ワードヒット

単語タイミングで画面の固定レーン（6箇所）に **白抜きバッジ** が 0.72秒間ポップアップします。  
レーンは直前と被らないようランダム選択。最大 **7個**同時表示。

---

### 文字（`onChar`）— キャラクタティック

1〜2文字の文字タイミングで **黄色の小さい正方形バッジ**（枠線あり）が8か所の固定ドット位置に 0.42秒間出現します。  
最大 **12個**同時表示。

---

### セクション（`onSection`）

現在は処理なし（セクション名バナー・スキャンラインエフェクトは削除済み）。

---

## 操作方法

- **▶ / Ⅱ / ■ / ↺ / |<**: 再生・一時停止・停止・先頭へ・歌詞の先頭へ
- **シークバー**: 任意の位置へ移動
- **音量スライダー**: 音量調整
- TextAlive ホスト接続時はホスト側の操作に追従します (文字サイズ・アクセント色のパラメータ対応)
